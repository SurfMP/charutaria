# Charutaria

Aplicativo (PWA) de controle de estoque de charutos. Funciona offline; os dados ficam no próprio celular (IndexedDB).

- Publicação: GitHub Pages, ramo `main`, pasta raiz.
- Para publicar uma correção, altere os arquivos e aumente `VERSAO` em `sw.js` e `VERSAO_APP` em `index.html`. O aplicativo instalado mostra "Nova versão disponível — Atualizar".
